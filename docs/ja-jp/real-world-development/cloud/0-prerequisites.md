Copilot cloud agent の演習を始める前に、必要なものを準備します。Tailspin Toys リポジトリのコピーを作成し、[Codespace][codespaces] を起動します。Codespace は、指示ファイルの編集や cloud agent が作成した作業のレビューに使用します。

## ラボ用リポジトリをセットアップする

作成するコードのためにリポジトリのコピーを作成します。[テンプレート][template-repository]からインスタンスを作成すると、ラボに必要なファイルがすべて含まれます。演習中はこのリポジトリを使用します。

1. 新しいブラウザーウィンドウで、[Tailspin Toys テンプレート][tailspin-template]に移動します。
2. ラボリポジトリのページで **Use this template** ボタンを選択し、リポジトリのコピーを作成します。続いて **Create a new repository** を選択します。

    ![Use this template ボタン](../../../_images/ex0-use-template.png)

3. GitHub または Microsoft が主催するイベントでワークショップを受講する場合は、メンターの指示に従ってください。それ以外の場合は、GitHub Copilot を利用できる組織に新しいリポジトリを作成できます。

    ![リポジトリテンプレートの設定を入力する画面](../../../_images/ex0-repository-settings.png)

4. 作成したリポジトリのパス（**organization-or-user-name/repository-name**）を控えてください。このラボの後半で使用します。

## Codespace を作成する

次に、Codespace を使ってラボの演習を完了します。

[GitHub Codespaces][codespaces] は、ブラウザー上で直接コードの作成、実行、デバッグを行えるクラウドベースの開発環境です。複数のプログラミング言語、拡張機能、ツールをサポートする、すべての機能を備えた IDE を利用できます。

1. 作成したリポジトリに移動します。
2. 緑色の **Code** ボタンを選択します。

    ![Code ボタンを選択する](../../../_images/ex0-code-button.png)

3. **Codespaces** タブを選択し、**+** ボタンを選択して新しい Codespace を作成します。

    ![新しい Codespace を作成する](../../../_images/ex0-create-codespace.png)

Codespace の作成には数分かかりますが、サービスを手動でインストールするよりもはるかに早く完了します。この間に GitHub Copilot の他の機能を確認してみましょう。次の演習で取り上げます。

> [!CAUTION]
> 今後の演習で Codespace に戻ります。しばらくの間、ブラウザーのタブを開いたままにしてください。

> [!NOTE]
> このワークショップは Codespace またはローカルの [dev container][dev-containers] 内で実行できるように構成されています。どちらの環境にも、スムーズに作業を進めるために必要な前提条件がすべてインストールされています。ローカルで作業する場合は、クローンしたリポジトリを VS Code で開き、プロンプトが表示されたら **Reopen in Container** を選択してください。Codespace と同じ dev container が VS Code によって構築されます。

[codespaces]: https://github.com/features/codespaces
[dev-containers]: https://code.visualstudio.com/docs/devcontainers/containers

## まとめ

ラボ用リポジトリのコピーを作成できました。また、Copilot cloud agent と一緒に作業するときに使用する Codespace の起動を開始しました。
