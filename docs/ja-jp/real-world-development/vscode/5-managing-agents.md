GitHub Copilot をエージェントモードにすると、コードベースの調査、変更の提案、ファイルの編集、コマンドの実行などを自律的に行います。VS Code の Copilot Chat では、すべてのツール呼び出しやファイルの編集がリアルタイムに表示されます。各差分をインラインでレビューし、個々の変更を承認または破棄できます。また、エディターを離れずに追加のプロンプトを送り、作業の改善や拡張を指示できます。

この演習では、次の操作を行います。

- アクセシビリティエージェントの作業をリアルタイムで監視します。
- 提案されたファイルの編集をレビューし、承認します。
- セッションの途中でエージェントを誘導し、ハイコントラストモードに加えてライトモードを追加します。

## シナリオ

[演習 4][previous-lesson]で使用したアクセシビリティ向けカスタムエージェントは、ハイコントラストモードを実装しています。作業中、デザインチームから追加の依頼がありました。既定のテーマが暗すぎると感じるユーザー向けに、ライトモードの切り替えも追加してほしいとのことです。新しい会話を最初から始める代わりに、現在のセッションを誘導して追加機能を実装します。

## Copilot の進捗を監視する

Copilot Chat ビューには、エージェントが行う各ステップ、調査するファイル、実行するコマンド、提案する編集が表示されます。ファイルの編集は差分と **Keep** / **Undo** の操作とともに、チャット内に表示されます。

1. 演習 4 で使用した Copilot Chat ビューに戻ります。
2. エージェントの作業中にチャットをスクロールし、各ツール呼び出しを確認します。ファイルの読み取り、ファイルの編集、実行を求めるターミナルコマンドが表示されます。
3. エージェントがファイルの編集を提案すると、差分がインラインで表示されます。
    - 変更を承認するには **Keep** を選択します。
    - 変更を元に戻してエージェントにもう一度作業させるには **Undo** を選択します。
4. チャットの上部にある **Files changed** の表示を開くと、セッション中にエージェントが変更したファイルの全体を確認できます。

> [!NOTE]
> ターミナルコマンドの実行などに許可が必要な場合、エージェントは一時停止して **Allow** を表示します。内容を確認し、問題のないコマンドのみ承認してください。

5. エージェントがハイコントラストモードを実装し終えるまで待ちます。最後に、変更内容をまとめたメッセージが表示されます。

## エージェントにライトモードの追加を依頼する

ハイコントラストモードを実装したら、同じ会話でライトモードの切り替えを追加します。同じチャットセッションを続けることで、エージェントはこれまでの作業内容を保持します。変更したコンポーネント、スタイルの方針、設定を local storage に保存するパターンなどを引き続き参照できます。

1. Copilot Chat の入力欄に、次の追加プロンプトを送信します。

    ```plaintext
    Nice work! Now add a light-mode toggle alongside the high-contrast toggle. Light mode should follow the same pattern — persist via local storage and be accessible from the same area of the UI. The user should be able to enable high-contrast and light mode independently.
    ```

2. エージェントがこれまでの変更を確認し、ライトモードに必要な変更を提案します。
3. ハイコントラストモードのときと同じように、新しい変更をレビューします。差分ごとに **Keep** または **Undo** を選択します。
4. たとえば、望ましくない方法でトグル UI をリファクタリングしようとした場合など、エージェントの進め方を変更したいときは、チャット入力欄の隣にある **Stop** ボタンで停止し、説明を追加したプロンプトを送信します。

> [!TIP]
> 進行中のセッションに指示を追加すると、最初からやり直すよりもすばやく作業を進められます。追加のプロンプトで調整（「CSS を簡潔にし、セレクターの重複ではなく CSS 変数を使用する」）、方向の修正（「3つ目のトグルを追加せず、既存の設定パネルにライトモードを追加する」）、範囲の拡張（「両方のトグルにキーボードショートカットも追加する」）を依頼できます。

## 作業ファイルをレビューする

変更をコミットする前に、エージェントが変更したファイルを確認します。

1. VS Code で **Source Control** ビューを開きます。
2. 変更されたファイルの一覧を確認します。Astro コンポーネント、スタイル、関連テストなどが更新されているはずです。
3. 変更されたファイルをいくつか開き、差分を確認します。カスタムエージェントからの指示が反映されていることを確認します。具体的には、ARIA 属性、キーボード操作、セマンティック HTML、local storage による設定の保存などです。
4. 内容に問題がなければ、**Source Control** パネルで変更をステージングしてコミットします。次のレッスンで公開します。

## まとめと次のステップ

Copilot Chat のエージェントモードで、進行中のセッションを監視して誘導しました。ファイルの編集を確認し、変更を承認または破棄し、コンテキストを保ったまま追加プロンプトを送って作業を拡張しました。

このレッスンでは、次の操作を行いました。

- エージェントの作業をリアルタイムで監視しました。
- 個々のファイル編集を承認または破棄しました。
- 追加プロンプトを使って、進行中のセッションを誘導しました。
